# 🔍 Item Seeker (Жезл Поиска)

[![Minecraft Version](https://img.shields.io/badge/Minecraft-1.12.2-blue.svg)](https://minecraft.net/)
[![Forge](https://img.shields.io/badge/ModLoader-Forge-orange.svg)](https://files.minecraftforge.net/)
[![Release](https://img.shields.io/badge/Version-1.0.0-purple.svg)](https://github.com/kimarsen/item-seeker/releases)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Item Seeker** — мощный утилитарный мод для **Minecraft Forge 1.12.2**, созданный для быстрого обнаружения любых предметов и ресурсов в мире. 

С помощью специального **Жезла Поиска** вы можете указать абсолютно любой предмет (как ванильный, так и из любых сторонних модификаций, например, *Амулет Жизни из Twilight Forest*, ресурсы из *IndustrialCraft 2*, *Applied Energistics 2*, *Thaumcraft* и т.д.), задать необходимый порог количества (например, `64`), и жезл мгновенно укажет координаты всех сундуков, печей, шалкеровых ящиков, загрузочных воронок, вагонеток с сундуками и любых блоков/сущностей с хранилищами, содержащих этот предмет в указанном количестве или больше.

## ✨ Ключевые возможности

* **Поддержка 100% контейнеров:**
  * Ванильные сундуки (включая корректный подсчёт в **двойных сундуках**).
  * Печи, раздатчики, выбрасыватели, воронки, варочные стойки, ящики шалкера.
  * Сущности-хранилища: вагонетки с сундуками, вагонетки с воронками, ослы/мулы/ламы с сундуками.
  * **Любые модовые контейнеры:** поддержка стандартных интерфейсов `IInventory` и Forge `CapabilityItemHandler` (Iron Chests, сундуки Tinkers' Construct, механизмы Thermal Expansion, Alchemistry и др.).
* **Гибкий фильтр предметов:**
  * Любой предмет перетаскивается в слот фильтра прямо в GUI без траты оригинала (фантомный слот).
  * Поддержка точного сравнения NBT-тегов или общего поиска по ID предмета.
* **Настройка порога количества (Threshold):**
  * Позволяет фильтровать только те хранилища, где предмет накопился в нужном объёме (например, найти только полные стаки по 64 шт.).
* **Асинхронный поиск по регион-файлам (.mca):**
  * Возможность сканировать даже **незагруженные чанки** всего сохранённого мира без принудительной генерации или лагов сервера.
* **Навигация и телепортация:**
  * Интерактивные кликабельные координаты в чате: `[ТП]` мгновенно перемещает игрока к найденному контейнеру.
  * Навигация по страницам результатов прямо в интерфейсе жезла.
* **Визуальные маркеры (ESP):**
  * Подсветка контейнеров сквозь стены (X-Ray) с маяками, уходящими в небо, и 3D-табличками с дистанцией и количеством предметов.

## 🕹️ Как получить и использовать

### Получение
Жезл доступен во вкладке креатива **«Item Seeker»** под названием **«Жезл Поиска»** (`itemseeker:seeker_wand`).

### Управление

| Действие | Назначение |
| :--- | :--- |
| **ПКМ** | Открыть интерфейс настройки жезла (выбор предмета, порога и области поиска). |
| **Shift + ПКМ** | Быстрый перезапуск поиска с текущими параметрами без необходимости заходить в меню. |
| **Клик в слот фильтра** | Положить предмет из руки в слот фильтра (или очистить кликом пустой рукой). |
| **Кнопка «НАЧАТЬ ПОИСК»** | Выполнить сканирование мира и вывести координаты в интерфейс, чат и 3D-мир. |

## 🖥️ Интерфейс Жезла Поиска

В графическом интерфейсе доступны следующие элементы:

1. **Слот искомого предмета:**
   * Отображает иконку и локализованное название целевого предмета.
   * Кнопка **«Очистить»** сбрасывает выбранный предмет.
2. **Поле ввода порога:**
   * Текстовое поле для ручного ввода любого числа.
   * Кнопки быстрой установки: `[ 1 ]`, `[ 16 ]`, `[ 32 ]`, `[ 64 ]`, `[ 128 ]`, `[ 256 ]`.
3. **Селектор области поиска:**
   * `Чанки: Загруженные` — мгновенный опрос всех загруженных в данный момент контейнеров в памяти.
   * `Радиус: 256 / 512 / 1024 блоков` — фильтрация по сферическому расстоянию от игрока.
   * `Весь мир (Регионы)` — глубокое сканирование `.mca` файлов сохранения мира.
4. **Переключатель NBT:**
   * `NBT: ВЫКЛ` — ищет любые предметы с данным ID (независимо от зачарований, прочности или данных).
   * `NBT: ВКЛ` — строгое совпадение всех NBT-тегов (для поиска конкретных уникальных артефактов).
5. **Панель результатов:**
   * Кнопки переключения `<` и `>` для просмотра всех найденных точек.
   * Индикатор: `№ / Всего`, тип контейнера, количество предметов и дистанция в метрах.
   * Кнопка **«ТП»** — мгновенный безопасный перенос игрока к контейнеру.
   * Кнопка **«Метка»** — включение/отключение персонального маяка для данной точки.

## 🌐 Режимы сканирования

* **Загруженные чанки (Loaded Chunks):**
  * Сканирует список активных `TileEntity` и `Entity` в оперативной памяти сервера.
  * Работает моментально (0–3 мс), идеально для поиска вещей на активных базах и вокруг игрока.
* **Радиус (Radius Mode):**
  * Ограничивает поиск заданной дистанцией (256, 512 или 1024 блока).
* **Весь мир (Region File Scanner):**
  * Считывает дисковые файлы региона (`r.X.Z.mca`) без загрузки чанков в игровой мир.
  * Безопасно для сервера: не вызывает спавн мобов, тики растений или утечки памяти.
  * Для загруженных чанков автоматически подставляет актуальные данные из RAM, гарантируя 100% точность.

## 🔮 3D-подсветка в мире (ESP & Beacons)

При успешном поиске или активации меток:
* Вокруг каждого найденного контейнера рисуется **полупрозрачный светящийся куб** (зелёный/бирюзовый для обычных результатов, золотой для отмеченных).
* Контейнеры видны **сквозь стены и любые препятствия**.
* Вверх поднимается **световой столб-маяк** высотой в 128 блоков, позволяющий ориентироваться на местности с большого расстояния.
* Над контейнером парит 3D-табличка с названием хранилища, количеством найденного ресурса и точным расстоянием до него:
  ```text
  Сундук (64) [85m]
  ```

## 💡 Примеры использования

### Пример 1: Поиск Амулета Жизни из Сумеречного Леса
1. Возьмите Жезл Поиска и откройте его на **ПКМ**.
2. Поместите **Амулет жизни** (`twilightforest:charm_of_life_1`) в слот фильтра.
3. Нажмите кнопку **`[ 64 ]`** или введите `64` в поле порога.
4. Выберите режим **«Чанки: Загруженные»** (или «Весь мир»).
5. Нажмите **`[ НАЧАТЬ ПОИСК ]`**.
6. В чате и на экране появится точный перечень координат всех сундуков с 64+ амулетами жизни, а в мире зажгутся световые маяки.

## ⚙️ Техническое устройство и оптимизация

* **Совместимость с Double Chest:**
  * Мод корректно связывает обе половины большого сундука в единое хранилище и предотвращает дублирование подсчёта.
* **Поддержка Forge Capabilities:**
  * Интеграция с `CapabilityItemHandler.ITEM_HANDLER_CAPABILITY` обеспечивает совместимость с модами на хранилища без хардкода конкретных классов.
* **Сетевой протокол:**
  * Использует `SimpleNetworkWrapper` с сжатой сериализацией результатов, исключая лаг-спайки сетевого пакета.

## 📥 Установка

1. Убедитесь, что у вас установлен **Minecraft Forge 1.12.2** (версии `14.23.5.2847` или новее).
2. Скачайте файл **`itemseeker-1.0.0.jar`** из раздела [Releases](https://github.com/kimarsen/item-seeker/releases).
3. Поместите jar-файл в папку `.minecraft/mods`.
4. Запустите игру!
